Netflix Clone — Style Guide

1. Overall Design

Create a modern, cinematic streaming application inspired by Netflix.

The application should feel professional, immersive, minimalistic, and visually polished.

Follow the provided wireframes for page layouts while applying consistent styling throughout the application.

2. Color Palette

Primary background: #141414 (Netflix dark gray)

Secondary background: #181818

Primary accent: #E50914 (Netflix red)

Primary text: #FFFFFF

Secondary text: #B3B3B3

Card hover background: #252525

Maintain strong contrast and avoid unnecessary bright colors.

3. Typography

Font family: Arial, Helvetica, sans-serif

Headings: Bold and prominent

Body text: Clean, readable, and consistent

Movie titles: Medium to bold

Secondary information: Smaller and muted

Establish a clear visual hierarchy.

4. Navigation

Use a fixed or sticky navigation bar.

Display the application logo prominently.

Keep navigation consistent across pages.

Highlight the currently selected page.

Provide subtle hover effects on navigation links.

5. Movie Cards

Display movie posters in consistent aspect ratios.

Use rounded corners subtly.

Maintain equal spacing between cards.

Add smooth hover animations.

Slightly enlarge cards when hovered over.

Ensure movie titles remain readable.

6. Layout and Spacing

Follow the supplied wireframes.

Use horizontal movie carousels where indicated.

Maintain consistent padding and margins.

Avoid overcrowding the interface.

Use responsive layouts for different screen sizes.

7. Animations and Interactions

Use subtle, purposeful animations.

Movie card hover: Smooth scaling

Buttons: Smooth color transitions

Page navigation: Minimal transitions

Carousel movement: Smooth horizontal scrolling

Interactive elements: Clear visual feedback

Avoid excessive animations that distract from the content.

8. Page-Specific Styling

Home Page

Feature movie recommendations prominently.

Organize movie posters into horizontal rows.

Use a cinematic dark background.

Movie Description Page

Feature a large movie poster or backdrop.

Display the movie title and description clearly.

Include a prominent button to add or remove the movie from the watchlist.

Personal Watchlist Page

Display saved movies in a clean, organized layout.

Maintain consistent movie card styling.

Make removing movies intuitive.

9. Responsive Design

Desktop: Full navigation and horizontal movie rows.

Tablet: Adjust spacing and the number of visible movie cards.

Mobile: Compact navigation and fewer cards per row.

Avoid horizontal page overflow.

10. Design Principles

Prioritize usability over decoration.

Maintain consistency across all pages.

Use reusable React components.

Keep the interface clean and intuitive.

Follow the wireframes without sacrificing usability.

Aim for a production-quality visual appearance.
