# Netflix Clone

A Netflix-style movie browser. The React front end is built; the Supabase back end is being designed.

## Layout

- `front-end/`: the React 19 + Vite app, plus its product spec in `front-end/app_outline/`.
- `supabase/`: database design (`schema.sql`, `erd.png`, `user_stories.md`, `api_notes.md`).
- `.claude/`: shared Claude Code skills and agents.
- `.mcp.json`: Supabase MCP server config.

## Run the front end

```bash
cd front-end
npm install
npm run dev
```
